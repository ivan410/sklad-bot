«Склад бот» — личное приложение, которым пользуется только его владелец.

Какие данные используются

  • Данные учёта, которые владелец вводит в Telegram-боте: товары, остатки, продажи, закупки, карточки устройств, заказы на ремонт, в том числе имена и телефоны клиентов, фото устройств.
  • Доступ к Google Диску владельца в объёме drive.file: бот видит и изменяет только те таблицы и папки, которые создал сам. Другие файлы владельца боту недоступны.

Где хранятся данные

Все данные хранятся только в Google Таблицах и на Google Диске владельца. Приложение не имеет собственной базы данных, не передаёт данные третьим лицам, не продаёт их и не использует для рекламы.

Удаление данных и отзыв доступа

Владелец может в любой момент удалить таблицы на своём Google Диске и отозвать доступ приложения на странице myaccount.google.com/permissions.

Использование данных Google

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования ограниченного использования (Limited Use).

Privacy policy (English). Sklad bot is a private app used only by its owner. It uses the drive.file scope to create and edit only its own spreadsheets and photo folder in the owner's Google Drive. Data is stored only in the owner's Google account, is never shared with or sold to third parties, and is not used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
